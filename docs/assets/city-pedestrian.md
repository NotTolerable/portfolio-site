## Derivative and preparation

[public/city/pedestrian.glb](../../public/city/pedestrian.glb) is generated by [scripts/prepare-city-pedestrian.mjs](../../scripts/prepare-city-pedestrian.mjs):

```sh
node scripts/prepare-city-pedestrian.mjs
```

The script parses the retained FBX, replaces the source material with a white rough PBR material, excludes textures and animation clips, welds identical vertices and applies Meshopt compression with attribute quantization. Source geometry and named rig nodes are retained; no mesh simplification, new body proportions or pose changes are baked into the GLB. The source FBX/PNG remain unchanged. No source download or additional package is required.

The output is **83,936 bytes**, with **1,604 triangles**, one skinned mesh, 44 skin joints and no embedded images or animation clips. It requires the existing Three.js bundled Meshopt decoder and uses `EXT_meshopt_compression` and `KHR_mesh_quantization`.

The 57 original named rig nodes remain present. The 13 unused `*_end` leaf bones load as ordinary named `Object3D` nodes; all 44 actual skin joints load as `THREE.Bone`. The bones used by `createWalkerRig` retain their exact names: `Hips`, `Chest`, `UpperChest`, `Head`, and paired `Left`/`Right` `Arm`, `ForeArm`, `UpLeg`, `Leg` and `Foot`. The remaining spine, neck, shoulder, hand, finger, toe and source controller joints are retained.

## Runtime integration

Load `/city/pedestrian.glb` with `GLTFLoader` and the bundled Meshopt decoder. Clone rigs with Three.js `SkeletonUtils.clone` so pedestrians have independent skeletons while sharing geometry and texture. Use the whole returned scene as the model root, then call **`prepareWalkerModel(model, idlePose)` exactly once**, before `createWalkerRig(model, pedestrianRoot)`. The exported GLB intentionally has raw source transforms: it is neither grounded nor height-normalized. Do not pre-normalize it in a second path or re-run preparation on an already prepared clone.

Load `/models/courier/skin.png` separately once and share the texture. Set `texture.colorSpace = THREE.SRGBColorSpace` and keep **`texture.flipY = true`** (the `TextureLoader` default). The GLB retains FBX UV coordinates and does not embed an image flip; the common glTF external-texture recipe of `flipY = false` would invert this particular skin. Assign that texture to the skinned mesh's material map. Source skin colors can be tinted through a per-person material while continuing to share the skin texture. Dispose shared resources only after all pedestrians are released.

With the existing idle pose and `prepareWalkerModel` proportions, the model's reference bounds in metres are:

## Verification

The preparation command round-trips the packed GLB through `GLTFLoader` and the bundled Three.js Meshopt decoder. It checks that all original named rig nodes, all walking-rig bones, UVs, skin indices, weights and triangle count survive; that no image or animation is embedded; and that prepared bounds differ from the original FBX by less than 1 mm. The measured maximum reference-bound difference is **0.0000968 m**. Runtime walking, routing and scene appearance are checked separately by the connected-city implementation.

## Phase 3 use

Seventeen independently posed background NPCs share this geometry and skin. The runtime remaps only the clothing/shoe atlas regions to restrained winter colors with a small material shader; the source PNG stays unchanged. Body heights, walking speed, start offsets and endpoint dwell vary. The original sportswear silhouette remains stylized; this is a background NPC solution, not a photorealistic human asset.
