# 0014 — Systems chamber, original sound and adaptive graphics

Status: accepted and implemented locally under the owner’s creative authorization. Date: 2026-10-27. Refines 0012/0013.

## Context

The owner reported deploying the previous gallery themselves and explicitly requested no deployment of this version. They requested frostier ice, scroll-based hotspot selection instead of camera distance, breathing glow, automatic rotation, stronger atmosphere, optional Igloo-like audio/game feel, an improved continuation after the fish, and automatic rendering simplification toward 60fps. They retained creative freedom while rejecting an Igloo ice-themed clone.

## Decision

Keep the personal black-ice opening and all factual content. Independently author a quiet graphite/teal/brass systems chamber after the three exhibits, replacing the fish and water crossing. A particle arrival resolves into a manufactured physical processor with instanced pins/traces, sparse arcs and an instrument platform. Keep the complete resume and contact finale.

Drive the single active halo by authored scroll stops; let it breathe slowly rather than flash abruptly. Keep automatic object rotation, hover offsets and drag accumulation as separate time-based channels. Honor pause/reduced motion.

Add original procedural Web Audio behind an explicit Sound toggle. Start muted, layer quiet ambience/travel response/UI cues, suspend when hidden and release all resources. Do not reuse reference audio.

Add measured automatic quality with warm-up, sampling windows, hysteresis/cooldown and recovery backoff. Reduce actual GPU work through DPR, draw ranges, transmission, effect cadence and secondary geometry. Give the lowest tier a deliberate pixelated canvas while keeping semantic HTML sharp. Offer persistent manual overrides. No universal 60fps guarantee.

## Consequences and verification

No new runtime dependencies, licensed reference code or assets are required. Graphics adaptation measures browser cadence, so external load and display limits can affect it; isolated long stalls are excluded. Physical materials are simplified on weak devices, and the UI/content remain intact. Current reference observations and proposals are distinguished in the study report.

Review this version at `localhost:3000`. No GitHub push, production merge or deployment is authorized by this request. The owner’s report of the earlier deployment is not a new agent-verified deployment event.
