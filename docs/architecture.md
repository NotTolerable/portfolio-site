## Rendering and assets

Renderer: antialiasing, sRGB output, ACES Filmic, exposure 1. The cool-graded CC0 studio HDR provides PMREM reflections, with RoomEnvironment fallback. `iceGeometry()` now intersects irregular cut planes and subtracts seven angled wedges to create genuinely chipped slabs. An installed Three MarchingCubes helper extracts each mesh once (approximately 8,800 triangles); its temporary geometry/material are disposed and no generation runs per frame. Bounds stay centered with the same exhibit height, preserving the camera/contents/contact contract.

`black-ice.ts` separates dark outer reflectance from relatively neutral transmitted light. Spatial frost coverage drives roughness between clearer windows and opaque-looking edges, using IOR 1.18, little clearcoat and variable physical thickness. Fine frost relief is sampled in object-space triplanar coordinates from a linearly filtered/mipmapped generated texture, avoiding stretched side-face UVs and the former broad chrome strips. The current exhibit refinement replaces rendered solid sports meshes with all-white three-dimensional particle forms derived from the original basketball/dumbbell geometry and licensed sculpted glove model. Shape/detail must remain recognizable through the ice, including cheaper graphics profiles. Fish/water and the manufactured processor pedestal are inactive.

`particle-sports.ts` fits and samples the transformed sports surfaces and instanced details once, then disposes their temporary solid geometry, materials and textures. Each returned exhibit contains one `Points` object with static positions/normals and white-only sprite shading. An interleaved detail sample preserves basketball seams, glove stitching and dumbbell plate/grip features in reduced draw ranges. High/Balanced/Performance/Low-spec use 18,000/12,500/7,600/5,000 points; density-aware point sizing keeps the shape legible. The sprites are opaque, round-discarded and depth-tested so Three’s physical transmission capture includes them; transparent additive points would not provide the same interior refraction. Renderer-supplied time controls restrained achromatic variation, and no independent RAF or per-frame point-position updates are introduced. Returned point resources are disposed with the scene. Quantized GLTF position/normal attributes are decoded to float before baking world transforms, preventing coordinate clipping/wrapping during sampling.

`glove-art.ts` loads Joachim Bornemann’s CC0 Vintage boxing gloves in parallel with the HDR, using Three’s bundled Meshopt decoder. It recenters each glove in its own transform wrapper, preserves encoded mesh transforms, and poses the pair cuff-up at unequal heights/depth with overlapping silhouettes. Two thin curved lace sources join at a shared suspension point; the complete arrangement is recentered before fitting inside the ice. The fallback uses the same hanging composition. The 1,362,116-byte geometry-only GLB retains sculpted thumbs, knuckle padding, cuffs, laces and stitched edges; it is sampled once and never rendered as a solid object. Failed asset loading falls back to the local glove source so the gallery remains usable. `scripts/prepare-glove-asset.py` exports simplified geometry using Blender, then `scripts/compress-glove-asset.mjs` applies existing build-time Meshopt tools. No textures, new package or external runtime service are required. The lace uses 6.5% of the existing point budget, leaving the rest for the glove bodies; it is sampled into the same Points object, with no added render call or per-frame animation. The latest owner request authorizes including this pose refinement in the complete production update.

The clarity refinement disables dispersion and reduces normal distortion/roughness in the central transmission calculation while retaining the granular reflective exterior and frosted edges. High uses a full-resolution transmission target; Balanced uses 0.75 resolution, and cheaper tiers retain their no-transmission path. This spends more transmission pixels for crisp interior dots; disabling three-channel dispersion reduces refraction sampling. Adaptive quality remains available; no net GPU cost or device frame-rate guarantee is inferred.

Each exhibit owns a `frost-field.ts` ping-pong history: two 256² half-float targets, reduced to 128² in cheaper tiers. Its red channel retains polish; signed green records the advancing/receding frontier. Fixed 60Hz simulation steps, capped at four per gallery frame, expand and weakly advect the mask while it decays. Real pointer events are distinguished from autorotation beneath a stationary cursor. Ray hits map to the same volume-attached UVs used by the material. First, stale or discontinuous hits establish a stroke origin instead of drawing a jump. A retained field continues decaying after exit; pause/reduced motion stop updates. No independent RAF is introduced. Quality changes copy the retained field, and rendering restores the caller’s target, viewport, scissor and clear state.

`triangle-pattern.ts` generates one shared 512² periodic irregular triangulation at initialization. `black-ice.ts` reveals these fine lines most strongly at the moving frontier and faintly inside the retained clearing, while reducing relief/roughness and clearing refraction. This replaces both the old Gaussian stamp approximation and the rejected 72-face highlight patch. Cheaper profiles retain the lower-resolution field and a spatial-opacity material without the physical refraction target.

`signals.ts` reads shell bounds, not shell faces, for a separate annular cloud of 18 drifting nodes. Stable shuffled pair priorities create persistent long links with up to three connections per node; band exit/wrap retires them over 0.35 seconds. Tiny rotating plus markers and noise-fragmented lines use two draw calls per exhibit. Reduced quality uses 12 nodes/two connections. Stationary hover does not stop this exterior network. The gallery’s existing clock freezes it on pause and provides a static reduced-motion composition.

The third shell erodes with scroll while its field gathers into the GPU. `gpu-hologram.ts` builds an original modern card silhouette: one large visible right-hand fan, broad left faceplate, central X/hourglass and perimeter frame, cooling fins, bracket, PCB and PCIe edge. It carries no branding. The renderer supplies a slanted pose and continuous Y rotation. Holographic surfaces provide scan bands, a fine grid and view-dependent rim; outlines and sampled points retain volume through rotation. Fan geometry rotates slowly. The card disperses before the resume. `runtime-core.ts` supplies only sparse corner marks; its circular orbit is removed. High draws up to 10,000 depth particles and approximately 39,100 GPU points from a bounded 48,000-point buffer; cheaper profiles reduce these. The sky develops a blue-hour horizon/cloud deck. Cursor atmosphere remains; fast meteors and the former physical stage are inactive.
`quality.ts` owns four measured frame-cadence tiers: High, Balanced, Performance and Low-spec. Auto starts high on desktop/balanced on narrow screens, ignores warm-up and long isolated stalls, evaluates 1.4-second windows, degrades after sustained slow frames and recovers only after extended headroom/backoff. Manual overrides persist in localStorage. Changes reduce DPR (desktop 1.7→1.15→.75→.6 caps), draw ranges, transmission and secondary geometry. Performance modes skip the grade pass and update the aurora less often; the lowest tier pixelates only the canvas. DOM labels, controls and resume remain full resolution. These are adaptations toward 60fps, not a hardware-independent promise.

`audio.ts` creates an original Web Audio graph after explicit opt-in. On first activation, an OfflineAudioContext renders a seamless 48-second stereo score of slowly overlapping chord pads and sparse upper notes. The final 24kHz float buffer is approximately 9.2MB and is cached for that audio instance; one looping source plays it, without live music oscillators or per-frame synthesis. Shared small buffers retain bright short hover tones on meteor and UI buttons, quieter typing blips and matching confirm/close sounds. The latest owner request authorizes the score and supersedes the earlier cue-only rule; rejected wind/noise, birdlike chirps and movement-triggered travel/contact loops remain absent. Dialogs duck the music; pause fades only the score while deliberate UI cues remain available. At most 16 one-shot cue voices run together, with master dynamics and a very quiet 19ms reflection. Mute and hidden tabs suspend; reading/failure modes mute or dispose; unmount stops sources and releases nodes/context/buffer references. Async activation is guarded against toggling/disposal races. Reference recordings are not loaded.
One RAF owns scroll, frame sampling, scene update, cursor/frost-field updates and rendering. React changes only chapter/modal/preferences/tier state. Hidden and reading views suspend rendering and reset timing samples. Tier transitions and resize use cooldowns. Geometry, materials, generated textures, each exhibit’s two frost targets, both atmosphere cursor targets, PMREM, composer, renderer, event listeners and audio are disposed by their owners.
